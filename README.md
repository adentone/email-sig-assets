# email-sig-assets

Static assets for HTML email signatures, served via jsDelivr:

`https://cdn.jsdelivr.net/gh/adentone/email-sig-assets@v1/icons/phone.png` (also mail.png, globe.png — 28x28 PNG, #6B7280, display at 14x14)

Icons rendered from [Lucide](https://lucide.dev) (ISC License). Do not delete or rewrite tags — live email signatures link here permanently.
